# Build the APK on Windows with Android Studio

1. Install Android Studio.
2. Extract this project.
3. Open the extracted folder in Android Studio.
4. Allow Gradle sync to complete.
5. If Android Studio asks for Android SDK 35, install it.
6. Select **Build**.
7. Select **Build Bundle(s) / APK(s)**.
8. Select **Build APK(s)**.
9. Click **locate** when the build completes.

The APK is normally located at:

`app\build\outputs\apk\debug\app-debug.apk`
